# Simulador 3D — instalador

Simulador de procesos productivos en 3D con un copiloto que arma, analiza y costea líneas de producción. Funciona sin internet.

## ⬇️ Descargar

### **[Descargar Simulador-3D-Instalador.exe](https://github.com/lucasviana2124/Simulador3D-releases/releases/latest/download/Simulador-3D-Instalador.exe)**

Ese enlace baja siempre la **última versión**. Es el único archivo que hace falta.

## Cómo instalar desde cero

1. Descargá **Simulador-3D-Instalador.exe** con el enlace de arriba (pesa unos 140 MB).
2. Abrilo. Si Windows muestra *"Windows protegió su PC"*, tocá **Más información → Ejecutar de todos modos**. Aparece porque el instalador no tiene un certificado de empresa; es normal.
3. Elegí la carpeta donde instalarlo (por ejemplo `D:\Simulador 3D`) y terminá.
4. Abrí **Simulador 3D** desde el acceso directo del escritorio o del menú Inicio.

**Requisitos:** Windows 10 u 11 de 64 bits.

## Preguntas frecuentes

**En la página de la versión hay varios archivos, ¿cuál bajo?**
Solo **Simulador-3D-Instalador.exe**. Los demás no hacen falta: `latest.yml` y `….blockmap` los usa el programa para buscar actualizaciones, y *Source code (zip / tar.gz)* lo agrega GitHub automáticamente (no es el programa).

**¿Cómo actualizo?**
Descargá el instalador de nuevo y ejecutalo: se instala encima, no hace falta desinstalar. También desde el programa: **⚙ Ajustes → Buscar actualizaciones**.

**¿Cómo lo desinstalo?**
Configuración de Windows → Aplicaciones → **Simulador 3D** → Desinstalar.

**¿Necesita internet?**
No. Solo se conecta si tocás *Buscar actualizaciones*.
